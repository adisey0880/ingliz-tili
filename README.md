# Ingliz tili — umumiy qo'llanma

O'zbek tilida ingliz tili bo'yicha umumiy qo'llanma — bitta HTML fayl, internetsiz ham ishlaydi.
83 ta mavzu.

## Bo'limlar

- **Asoslar** — alfavit va spelling, sonlar, katta sonlar, tartib sonlar va sana, vaqt, pul, kasrlar
- **Grammatika asoslari** — gap tuzilishi va asosiy qoidalar
- **Jonli nutq** — kundalik muloqot uchun iboralar
- **Talaffuz** — o'qish qoidalari
- **Qiyin tovushlar** — o'zbeklar uchun eng qiyin keladigan tovushlar
- **Murakkab grammatika** — chuqurroq mavzular
- **Lug'at va iboralar**

## Texnik tomoni

Bitta `index.html`. Hech qanday build, framework yoki server kerak emas —
faylni brauzerda ochsangiz ham ishlayveradi. Tashqaridan faqat Google Fonts yuklanadi.

## Yonidagi loyihalar

- **Zamonlar** — ingliz tilining 12 ta zamoni bo'yicha alohida qo'llanma
- **My Vocabulary** — so'z yodlash ilovasi (kartochka, test, yozib mashq, eshitib yozish + takrorlash sikli)
